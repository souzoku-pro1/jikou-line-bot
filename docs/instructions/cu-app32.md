# App 32「同封物ブロックマスタ」作成 完全指示書（Computer Use 用）

**開いている kintone でアプリ「同封物ブロックマスタ」を新規作成する。以下の手順を上から順に実行する。**

> ## ⚠ 最重要ルール（前回の失敗の再発防止）
> **フィールドコードは日本語のまま、この指示書の表記を一字一句コピペすること。**
> **英語への意訳（例: `ブロックキー` → `block_key`）は絶対に禁止。**
> 自動採番で `文字列__1行_` 等になった場合のみ、指示の日本語コードに修正する。

この指示書は自己完結している。フィールド数は **7個**。
文章ブロックの中身（レコード）の登録は**この作業に含まれない**（後で人間が登録する）。

---

## 0. 前提確認（最初に必ず行う）

1. 現在のタブに kintone のポータル画面（URL が `https://～.cybozu.com/k/` で始まる）が開いていることを確認する。
2. 開いていない・ログイン画面・別サービスの場合は、**操作せず中止し報告**する。
3. 途中で予期しないダイアログが出たら、無理に進めず内容を報告して停止する。

---

## 1. アプリの新規作成

1. ポータルの「アプリ」横の **＋（アプリを作成）** → **「はじめから作成」**
2. アプリ名を次に変更：

```
同封物ブロックマスタ
```

## 2. フィールド追加の共通操作

**手順A**: 左のパーツ一覧から指定パーツをドラッグ＆ドロップ → 歯車 → 設定 → フィールド名をコピペ入力
**手順B**: 設定画面下部の**フィールドコード**（鉛筆アイコン）を確認し、指示と違えば指示の値をコピペで入力 → 保存

## 4. 保存前のセルフチェック（必ず実施）

1. **7個すべて**のフィールドコードを設定画面で確認し、§3 と一字一句同じであること。
   **英語コードが1つでもあれば必ず日本語に修正**する
2. 重点確認: `ブロックキー` の重複禁止 ON／`対象ユニット` の選択肢4つ（順序込み）／
   `返送要否` の初期値 不要／`有効` の yes/no（半角小文字）と初期値 yes
3. フィールド総数が **7個**であること

- 「同封物ブロックマスタ」以外のアプリを開く・変更すること
- 迷ったら推測で進めず停止して報告
