## 0. 前提確認（最初に必ず行う）

1. kintone ポータルから **アプリ「人物」** を開く（URL が `https://～.cybozu.com/k/34/` になることを確認。**34 以外なら中止して報告**）
2. 画面右上の **歯車アイコン（アプリの設定）→「フォーム」** を開き、フォーム編集画面にする

4. 途中で予期しないダイアログ・エラーが出た場合は、無理に進めず内容を報告して停止する

## 1. フィールド追加の共通操作

**手順A:** パーツ一覧から指定パーツをフォームの**空いている場所**（既存フィールドの下）へドラッグ＆ドロップ → 歯車 → 「設定」 → フィールド名を**コピペ**
**手順B:** 設定画面下部の**フィールドコード**を確認し、指示と違えば**コピペで**修正 → 保存

⚠ フィールド名・フィールドコード・選択肢は**必ずコピペ**。**選択肢の末尾に空白を入れない。**
⚠ **既存フィールドの設定画面は開かない**（誤変更防止。追加した新フィールドのみ操作する）

**テーブルへの列追加（§3 で使用）:**
指定パーツを**既存テーブルの枠の中**（既存列の右隣）へドラッグ＆ドロップし、通常どおり設定する。**既存の列には触れない。**

## 4. 保存前のセルフチェック（必ず実施）

1. **追加した21項目**（トップ14＋テーブル列7）のフィールドコードを 歯車 → 設定 で §2〜§3 と一字一句突合する
2. **既存フィールドを1つも変更・削除・移動していない**ことを確認する（フォーム上の既存項目がすべて元のまま存在すること）
3. 特に次の4点を重点確認:
   - `父人物ID` `母人物ID` `養父人物ID` `養母人物ID` の4つがすべて存在（ID は半角大文字）
   - テーブル `身分事項` に**新しい5列が入っている**こと（テーブルの外に落ちていない）・`登場戸籍` に新しい2列
   - テーブル内 `日付` が**文字列（1行）**であること
   - ラジオボタン4つ（被相続人・名寄せ確定・相続人候補・除籍済み）が `no`/`yes` 半角小文字・初期値 `no`

## 7. 禁止事項

- **既存フィールドの変更・削除・移動・改名**（フィールドコードの変更を含む。最重要）
- 指示書にないフィールドの追加（`相続資格` は既存があるため追加しない）
- 選択肢の言い換え・追加・並べ替え
- アクセス権・APIトークン・Webhook・一覧・通知の設定（スコープ外）
- アプリ番号34以外のアプリを開く・変更すること
- 迷ったとき・画面が指示と食い違うときに推測で操作を続けること（停止して報告する）
