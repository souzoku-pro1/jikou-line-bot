# App 36（予定）「相続人」作成 完全指示書（Computer Use 用）

**開いている kintone でアプリ「相続人」を新規作成する。以下の手順を上から順に実行する。**

この指示書は自己完結している。外部の設計書・リポジトリを参照する必要はない。
フィールド数は **16個**（正本: docs/souzoku-shorui/01-data-schema.md §2〔App 37 相続人〕からの転記。
レコード番号フィールドは kintone が自動で持つため追加しない）。
アプリ番号は作成順で自動採番される（36 は予定。実番号は完了報告の URL で確定する）。

---

## 0. 前提確認（最初に必ず行う）

1. 現在のブラウザタブに **kintone のポータル画面**（URL が `https://～.cybozu.com/k/` で始まり、「アプリ」の一覧が見える画面）が開いていることを確認する。
2. **開いていない場合・ログイン画面が出ている場合・別のサービスが表示されている場合は、一切の操作をせず作業を中止し、「kintone ポータルが開いていないため中止した」と報告して終了する。**
3. 途中で予期しないダイアログ・エラー・確認画面が出た場合も、無理に進めず、その画面の内容を報告して停止する。

---

## 1. アプリの新規作成

1. **＋ ボタン（アプリを作成）** → **「はじめから作成」**
2. アプリ名欄を次の名前に書き換える：

```
相続人
```

---

## 2. フィールド追加の共通操作（この2つの手順を各フィールドで繰り返す）

**手順A:** パーツをドラッグ＆ドロップ → 歯車 → 「設定」 → フィールド名を**コピペ**
**手順B:** 設定画面下部の**フィールドコード**を確認し、指示と違えば**コピペで**修正 → 保存

⚠ フィールド名・フィールドコード・選択肢は**必ずコピペ**。**選択肢の末尾に空白を入れない。**

## 4. 保存前のセルフチェック（必ず実施）

1. **16個すべて**のフィールドコードを 歯車 → 設定 で §3 と一字一句突合する
2. 特に次の4点を重点確認:
   - `生年月日` が**文字列（1行）**であること（日付パーツにしない）
   - 続柄の `甥姪（代襲）` `受遺者（相続人外）`・状態の `未成年（特別代理人要）` の括弧が**全角**
   - `戸籍確認済`（「済み」ではなく「済」）の選択肢 `no`/`yes` 半角小文字・初期値 `no`
   - 財産アプリと違い、このアプリに `有効` フィールドは**ない**（追加しない）
3. フィールドの総数が **16個**であること

## 7. 禁止事項

- 指示書に**ないフィールドの追加**（ラベル・スペース・罫線・テーブルも置かない）、指示された16個以外の**削除**
- フィールド名・フィールドコード・選択肢の**言い換え・追加・並べ替え**（一字一句この指示書のとおり）
- アクセス権・APIトークン・Webhook・一覧・通知の設定（**今回のスコープ外**。別途人間が実施する）
- 他の既存アプリを開く・変更する・削除すること
- 迷ったとき・画面が指示と食い違うときに推測で操作を続けること（**停止して報告**する）
