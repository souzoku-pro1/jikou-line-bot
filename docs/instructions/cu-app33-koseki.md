# App 33（予定）「戸籍（読解）」作成 完全指示書（Computer Use 用）

**開いている kintone でアプリ「戸籍（読解）」を新規作成する。以下の手順を上から順に実行する。**

この指示書は自己完結している。外部の設計書・リポジトリを参照する必要はない。
フィールド数は **22個**（正本: docs/koseki-ocr/02-data-schema.md §1〔App 44 戸籍〕からの転記。
レコード番号フィールドは kintone が自動で持つため追加しない）。
アプリ番号は作成順で自動採番される（33 は予定。実番号は完了報告の URL で確定する）。

---

## 0. 前提確認（最初に必ず行う）

1. 現在のブラウザタブに **kintone のポータル画面**（URL が `https://～.cybozu.com/k/` で始まり、「アプリ」の一覧が見える画面）が開いていることを確認する。
2. **開いていない場合・ログイン画面が出ている場合・別のサービスが表示されている場合は、一切の操作をせず作業を中止し、「kintone ポータルが開いていないため中止した」と報告して終了する。**
3. ⚠ ポータルには**既存の「戸籍」という別アプリが存在する**。それは開かない・変更しない。今回作るのは新規アプリ「戸籍（読解）」である。
4. 途中で予期しないダイアログ・エラー・確認画面が出た場合も、無理に進めず、その画面の内容を報告して停止する。

---

## 1. アプリの新規作成

1. ポータル画面の「アプリ」見出しの右にある **＋ ボタン（アプリを作成）** をクリック
2. 作成方法の選択画面で **「はじめから作成」** をクリック
3. フォーム編集画面が開く。左上のアプリ名欄（「新しいアプリ」と表示）をクリックし、次の名前に書き換える：

```
戸籍（読解）
```

---

## 2. フィールド追加の共通操作（この2つの手順を各フィールドで繰り返す）

**手順A（パーツの配置と設定）:**
1. 画面左のパーツ一覧から指定のパーツをフォーム中央へ**ドラッグ＆ドロップ**する
2. 置いたパーツにマウスを乗せ、右上に出る **歯車アイコン → 「設定」** をクリック
3. 「フィールド名」に指定の名前を**コピペで**入力する

**手順B（フィールドコードの確認・変更）:**
1. 同じ設定画面の**下部にある「フィールドコード」**の値を確認する（鉛筆アイコンをクリックすると編集できる）
2. 自動で入った値が指示と違う場合、**指示のフィールドコードをコピペで**入力し直す
3. 「保存」をクリックして設定画面を閉じる

⚠ フィールド名・フィールドコード・選択肢は**必ずコピペ**すること。**選択肢の末尾に空白を入れないこと。**
⚠ **日付フィールドは「レコード登録時の日付を初期値にする」のチェックを必ず外す**こと。

## 4. 保存前のセルフチェック（必ず実施）

1. フォーム上の**22個すべてのフィールド**について、1つずつ 歯車 → 設定 を開き、**フィールドコード**が §3 の指定と一字一句同じかを確認する
2. 違うものがあれば、その場で修正して保存する
3. 特に次の5点を重点確認:
   - `Drive_fileId`（大文字小文字・半角アンダースコア）
   - `読解JSON`（半角大文字 JSON）
   - `従前戸籍_本籍` / `従前戸籍_筆頭者` / `新戸籍_本籍`（半角アンダースコア）
   - 戸籍種別の選択肢の括弧が**全角**（`改製原（平成）` `改製原（昭和）`）
   - `編製日`・`消除日` が**文字列（1行）**であること（日付パーツにしない・和暦原文保持）
   - 日時（確認日時）の**初期値チェックが外れている**こと
4. フィールドの総数が **22個**であること（多くても少なくてもいけない）

## 6. 完了報告（この様式で報告する）

作業完了後、次の2点を**画面から実際に読み取って**報告する:

1. **作成されたアプリの URL**（公開後にアプリを開き、アドレスバーの `https://～.cybozu.com/k/数字/` をそのまま転記。**数字がアプリ番号**）
2. **フィールドコード一覧**: 設定 → フォーム から22個のフィールドコードを §3 の番号順に列挙する（読み取れなかったものは「未確認」と正直に書く）

報告様式:
```
アプリURL: https://～.cybozu.com/k/NN/
フィールドコード一覧:
1. ユニット種別
2. 案件アプリID
（…22まで）
相違・未確認: （あれば列挙、なければ「なし」）
```

## 7. 禁止事項

- 指示書に**ないフィールドの追加**（ラベル・スペース・罫線・テーブルも置かない）、指示された22個以外の**削除**
- フィールド名・フィールドコード・選択肢の**言い換え・追加・並べ替え**（一字一句この指示書のとおり）
- アクセス権・APIトークン・Webhook・一覧・通知の設定（**今回のスコープ外**。別途人間が実施する）
- **既存アプリ「戸籍」を含む**他のアプリを開く・変更する・削除すること
- 迷ったとき・画面が指示と食い違うときに推測で操作を続けること（**停止して報告**する）
