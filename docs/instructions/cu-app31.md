# App 31「市区町村マスタ」作成 完全指示書（Computer Use 用）

**開いている kintone でアプリ「市区町村マスタ」を新規作成する。以下の手順を上から順に実行する。**

> ## ⚠ 最重要ルール（前回の失敗の再発防止）
> **フィールドコードは日本語のまま、この指示書の表記を一字一句コピペすること。**
> **英語への意訳（例: `団体コード` → `municipality_code`）は絶対に禁止。**
> フィールド名とフィールドコードは原則同じ日本語文字列である。
> 自動採番で `文字列__1行_` 等になった場合のみ、指示の日本語コードに修正する。

この指示書は自己完結している。フィールド数は **14個**。
初期データの投入（全国の市区町村約1,741件）は**この作業に含まれない**（後で別途プログラムが行う）。

## 0. 前提確認（最初に必ず行う）

1. 現在のタブに kintone のポータル画面（URL が `https://～.cybozu.com/k/` で始まる）が開いていることを確認する。
2. 開いていない・ログイン画面・別サービスの場合は、**操作せず中止し報告**する。
3. 途中で予期しないダイアログが出たら、無理に進めず内容を報告して停止する。

## 4. 保存前のセルフチェック（必ず実施）

1. **14個すべて**のフィールドについて 歯車 → 設定 を開き、フィールドコードが §3 と一字一句同じか確認。**英語コードが1つでもあれば必ず日本語に修正**する
2. 重点確認: `団体コード` の重複禁止チェック ON／`FAX番号` の半角大文字／
   `手数料_` 4つのアンダースコアと初期値（450・750・300・300）／`有効` の yes/no（半角小文字）と初期値 yes
