# CU 手順書: App 21（案件）— 委任契約書 CloudSign 登録（CONTRACT-GEN-2）

対象: 大野（kintone 管理者権限で実施）
所要: 約 5 分。実施後に daily_healthcheck の App21 警告が消えます。

## 前提（確認のみ・追加不要のはず）

以下 2 フィールドは既存です（cloudsign_document_id は締結 Webhook が本番で
使用中）。フォーム設定画面で**フィールドコードが完全一致**していることだけ
確認してください。

| フィールド名 | 型 | フィールドコード |
|---|---|---|
| メールアドレス | 文字列（1行） | `メールアドレス` |
| cloudsign_document_id | 文字列（1行） | `cloudsign_document_id` |

万一存在しない場合のみ、上記の名前・型・コードで新規追加してください。

## 手順 1: 契約書ステータスの選択肢を 3 つ追加

1. App 21 を開く → 右上の歯車（アプリ設定）→「フォーム」
2. 「契約書ステータス」（ドロップダウン）の設定を開く
3. 既存 4 択の**下に**次の 3 つを追加（コピペ・完全一致必須）:

```
クラウドサイン登録
クラウドサイン登録中
クラウドサイン登録済
```

4. 最終形（7 択・この並び推奨）:

```
契約書作成
契約書作成中
契約書作成済
クラウドサイン登録
クラウドサイン登録中
クラウドサイン登録済
要確認
```

5. 「保存」→ 画面右上の**「アプリを更新」を必ず実行**

## 手順 2: 動作確認（テスト 1 件）

1. 契約書作成済みの案件（「委任契約書」欄に docx 添付あり）を開き、
   「メールアドレス」に依頼者のメールアドレスを入力して保存
2. 「契約書ステータス」を **クラウドサイン登録** に変更して保存
3. 数秒〜十数秒後にレコードを再読込し、以下を確認:
   - ステータス = **クラウドサイン登録済**
   - `cloudsign_document_id` に ID が入っている
4. CloudSign 画面（下書き一覧）に「委任契約書_案件No.〇〇」があり、
   PDF が添付され宛先（氏名+メール）が設定されていることを確認
5. **送信は自動では行われません**。内容確認のうえ、送信操作は CloudSign
   画面で大野が実施してください（対外効果の一線・裁定済み方針）

## 運用メモ

- 前提未充足（docx 未添付/メールアドレス未入力・形式不正/氏名・住所・
  債権者の欠落）の場合は登録されず、不足項目名が LINE 通知されます。
  解消後にステータスを「クラウドサイン登録」へ設定し直してください。
- 「要確認」になった場合: CloudSign 画面で下書きの有無を確認し（重複が
  あれば削除）、再実行はステータスを「クラウドサイン登録」に戻します。
- 送信後の締結検知〜「締結済み」反映は既存の CloudSign Webhook
  （`cloudsign_document_id` 照合）がそのまま動きます。
