# CU 手順書: 財産目録の自動生成（ZAISAN-GEN-1）

対象: 大野（kintone 管理者権限で実施）
所要: 約 10 分。実施後に daily_healthcheck の App26/App35 警告が消えます。

## 手順 1: App 35（財産）へ 3 フィールド追加

App 35 を開く → 歯車（アプリ設定）→「フォーム」→ 以下を追加
（フィールド名とフィールドコードを**同一・完全一致**で。コピペ推奨）:

| フィールド名 | 型 | フィールドコード |
|---|---|---|
| 資料番号 | 文字列（1行） | `資料番号` |
| 相続開始時残高 | 数値 | `相続開始時残高` |
| 現在残高 | 数値 | `現在残高` |

保存 → **「アプリを更新」を必ず実行**。

- 資料番号: 目録末尾の資料綴りの番号（A〜D 全部で使用・空欄可）
- 相続開始時残高: **B 部（預貯金）の小計・総合計はこの値で算定**（裁定）。
  未入力の預貯金行があると目録は小計を空欄にし注記を出します
- 現在残高: 表示のみ（集計には使いません）

## 手順 2: App 26（相談カード・相続）へ 2 フィールド追加

App 26 を開く → 歯車 →「フォーム」→ 以下を追加:

1. **ドロップダウン**: フィールド名・コードとも `財産目録ステータス`、
   選択肢は次の 4 つ（コピペ・完全一致・この並び）:

```
財産目録作成
財産目録作成中
財産目録作成済
要確認
```

2. **添付ファイル**: フィールド名・コードとも `財産目録`

保存 → **「アプリを更新」を必ず実行**。

## 手順 3: App 26 に Webhook 行を追加

1. App 26 → 設定 → Webhook → 既存の**送付状 Webhook の URL をコピー**
2. URL の `/document/` を `/zaisan/` に置換（他は一字も変えない・https 確認）
3. 通知イベントは**「レコードの編集」にチェック** → 保存
4. **「アプリを更新」を必ず実行**（忘れると送信されません）

## 手順 4: 動作確認（テスト 1 件）

1. App 35 に対象案件の財産行が登録されていることを確認（案件アプリID=26・
   案件レコードID=対象案件の番号・有効=yes）。**評価確定=yes が揃っていなく
   ても生成できます**（ZAISAN-GEN-2 裁定）——未確定行がある場合は
   「下書き」として生成され、表題上のバナー・行備考の「※評価未確定」・
   小計/総合計の「（暫定）」で完成版と区別されます（評価確定の操作は
   弁護士の専権のまま）。全行確定+金額入力済みなら注記なしの完成版です
2. 預貯金行には「相続開始時残高」を入力（未入力だと小計が注記になります）
3. App 26 の対象案件で「財産目録ステータス」を **財産目録作成** に変更して保存
4. 数秒〜十数秒後に再読込し、ステータス=**財産目録作成済**・「財産目録」欄に
   xlsx が添付されていることを確認
5. xlsx を開き、A〜D 各部・小計・総合計（=A+B+C−D）・書式が原本どおりで
   あることを確認

## 運用メモ

- 「要確認」になった場合: 添付内容を確認し、再生成は添付を削除して
  ステータスを「財産目録作成」に戻します
- 持分評価格は「2分の1」「1/2」の書式の持分から自動算定（端数切捨て）。
  その他の書式は空欄になり備考に明示されます
- テンプレートの書式を変えたいときは、Desktop/claude の原本 xlsx を更新 →
  票で「テンプレ再収載」を依頼してください（SHA pin の更新が必要です）
