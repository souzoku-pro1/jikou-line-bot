# App 34（予定）「人物」作成 完全指示書（Computer Use 用）

**開いている kintone でアプリ「人物」を新規作成する。以下の手順を上から順に実行する。**

この指示書は自己完結している。外部の設計書・リポジトリを参照する必要はない。
フィールド数は **トップレベル21個（うちテーブル2個）＋テーブル内部7個**
（正本: docs/koseki-ocr/02-data-schema.md §2〔App 43 人物〕からの転記）。
アプリ番号は作成順で自動採番される（34 は予定。実番号は完了報告の URL で確定する）。

---

## 0. 前提確認（最初に必ず行う）

1. 現在のブラウザタブに **kintone のポータル画面**（URL が `https://～.cybozu.com/k/` で始まり、「アプリ」の一覧が見える画面）が開いていることを確認する。
2. **開いていない場合・ログイン画面が出ている場合・別のサービスが表示されている場合は、一切の操作をせず作業を中止し、「kintone ポータルが開いていないため中止した」と報告して終了する。**
3. 途中で予期しないダイアログ・エラー・確認画面が出た場合も、無理に進めず、その画面の内容を報告して停止する。

---

## 1. アプリの新規作成

1. ポータル画面の「アプリ」見出しの右にある **＋ ボタン（アプリを作成）** をクリック
2. **「はじめから作成」** をクリック
3. アプリ名欄を次の名前に書き換える：

```
人物
```

---

## 2. フィールド追加の共通操作（この2つの手順を各フィールドで繰り返す）

**手順A（パーツの配置と設定）:**
1. 画面左のパーツ一覧から指定のパーツをフォーム中央へ**ドラッグ＆ドロップ**する
2. 置いたパーツにマウスを乗せ、右上に出る **歯車アイコン → 「設定」** をクリック
3. 「フィールド名」に指定の名前を**コピペで**入力する

**手順B（フィールドコードの確認・変更）:**
1. 設定画面**下部の「フィールドコード」**を確認する（鉛筆アイコンで編集）
2. 自動採番の値になっている場合、**指示のフィールドコードをコピペで**入力し直す
3. 「保存」をクリック

⚠ フィールド名・フィールドコード・選択肢は**必ずコピペ**。**選択肢の末尾に空白を入れない。**
⚠ 日付フィールドは**「レコード登録時の日付を初期値にする」のチェックを外す**。

**テーブル（サブテーブル）の作り方（フィールド17・18で使用）:**
1. パーツ一覧から **「テーブル」** をフォームへドラッグ＆ドロップ
2. テーブルの 歯車 → 設定 で**テーブル自体のフィールド名・フィールドコード**を設定して保存
3. 指定された内部フィールドのパーツを**テーブルの枠の中へ**ドラッグ＆ドロップし、通常どおり 歯車 → 設定 でフィールド名・フィールドコードを設定する
4. 内部フィールドは**指定のものだけ**（テーブルに余分な列を作らない・テーブル配置時に自動で入る列があれば指定の列に置き換える）

## 4. 保存前のセルフチェック（必ず実施）

1. **トップレベル21個＋テーブル内部7個**のフィールドコードを1つずつ 歯車 → 設定 で開き、§3 と一字一句突合する
2. 違うものがあれば、その場で修正して保存する
3. 特に次の6点を重点確認:
   - `氏名_原文` / `氏名_正字` / `相手方氏名_原文`（半角アンダースコア）
   - `父人物ID` `母人物ID` `養父人物ID` `養母人物ID` `相手方人物ID` `記載元戸籍ID` `戸籍ID` の ID が**半角大文字**
   - テーブル `身分事項` の内部が **5列ちょうど**・`登場戸籍` の内部が **2列ちょうど**（余分な自動生成列が残っていないこと）
   - テーブル内 `日付` が**文字列（1行）**であること（日付パーツにしない）
   - ラジオボタン4つ（被相続人・除籍済み・名寄せ確定・相続人候補）の選択肢が `no` / `yes` 半角小文字・初期値 `no`
   - 生年月日・死亡日の**初期値チェックが外れている**こと
4. トップレベルの総数が **21個**であること（多くても少なくてもいけない）

## 6. 完了報告（この様式で報告する）

作業完了後、次の2点を**画面から実際に読み取って**報告する:

1. **作成されたアプリの URL**（`https://～.cybozu.com/k/数字/` をそのまま転記。数字がアプリ番号）
2. **フィールドコード一覧**（§3 の番号順。テーブルは内部列も併記）

報告様式:
```
アプリURL: https://～.cybozu.com/k/NN/
フィールドコード一覧:
1. ユニット種別
（…）
17. 身分事項（内部: 種別 / 日付 / 相手方人物ID / 相手方氏名_原文 / 記載元戸籍ID）
18. 登場戸籍（内部: 戸籍ID / 除籍済み）
（…21まで）
相違・未確認: （あれば列挙、なければ「なし」）
```

## 7. 禁止事項

- 指示書に**ないフィールドの追加**（ラベル・スペース・罫線も置かない）、指示されたもの以外の**削除**
- フィールド名・フィールドコード・選択肢の**言い換え・追加・並べ替え**（一字一句この指示書のとおり）
- アクセス権・APIトークン・Webhook・一覧・通知の設定（**今回のスコープ外**。別途人間が実施する）
- 他の既存アプリを開く・変更する・削除すること
- 迷ったとき・画面が指示と食い違うときに推測で操作を続けること（**停止して報告**する）
