# 07. 弁護士がやる意味の明文化（LP 訴求骨子）

行政書士・補助金コンサルとの差別化を「申請にとどまらない事業法務」として整理する。
LP・SEO 記事・Bot の営業案内カテゴリの回答は、この骨子から生成する。

## 1. 差別化の構造

| 観点 | 一般的な申請支援（コンサル・行政書士） | 当事務所（弁護士） |
|---|---|---|
| 申請書類の作成支援 | ○ | ○（同等。ここでは差がつかない前提に立つ） |
| **交付規程・不正受給リスクの法的助言** | △ | ◎ 経費対象の解釈・目的外使用・返還請求リスクを法的に判断できる |
| **取引契約のチェック** | ✗ | ◎ 補助事業で発生する外注・開発委託・売買契約のレビューまで一体受任 |
| **下請法・独禁法** | ✗ | ◎ 補助事業の発注側/受注側どちらでも下請法の助言（BtoB 顧客に刺さる） |
| **労務（賃上げ要件）** | △ | ◎ 賃上げ加点・賃金要件の就業規則/雇用契約への落とし込み |
| 不採択・返還請求・事務局対応 | ✗ | ◎ 万一の争訟・行政対応まで同一窓口 |
| 守秘・利益相反管理 | 業者による | 弁護士法上の義務として制度的に担保 |

## 2. LP 訴求骨子（見出し案）

1. 「補助金の申請代行」ではなく「補助金を使う事業の法務」— 申請は入口、契約・労務・
   下請法まで一人の弁護士が見る
2. 採択後こそリスクがある — 経費の対象外認定・返還請求。**とれる補助金**より
   **守れる補助金**（不正受給の防波堤という安心訴求）
3. 自動化による低価格と、弁護士による品質の両立 — 定型作業はシステム、判断は弁護士
   （診断は LINE で無料・数分、の導線）
4. 着手金＋成功報酬の明朗会計（06 の構造。タイミングは公募ごとに明示）
5. 埼玉・川口の地域事業者に（所在地は config・移転対応の既存原則）

## 3. Bot・書類への反映（実装に落ちる点だけ）

- 営業案内カテゴリ（02 §5）の定型回答はこの骨子の要約文（config で差し替え可能）
- 診断結果の提示文に「申請可否だけでなく、補助事業の契約・労務のご相談も承ります」を定型挿入
- **広告・表示の注意**: 「採択率○%」「確実に採択」等の表示は禁則（02 §5 と同じ縛りを
  LP 制作側のチェックリストにも展開。弁護士広告規程との整合は弁護士が最終確認）

## 4. 支援機関要件の扱い（受任範囲の判断材料）

- 事業再構築系など「認定経営革新等支援機関の確認書」が必要な公募は、公募マスタの
  `支援機関要件` に登録し、**受任判断の警告に自動表示**（当事務所が認定支援機関で
  ない場合、確認書は外部機関に依頼する段取りが必要 — 受任するかは弁護士判断）
- 商工会議所の様式確認が必要な公募（持続化）も同様にマスタで表現（必要書類行に
  「商工会議所の事業支援計画書（様式4）」を持たせ、チェックリストに自動反映）
