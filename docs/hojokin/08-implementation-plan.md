## 3. 推奨実装順序

| 順 | タスク | 備考 |
|---|---|---|
| 1 | K1 → K3、K10 | マスタ基盤と締切監視。**K3+K10 は診断 Bot より先に単体価値**（公募情報の自動収集と締切警報だけでも運用が始まる） |
| 2 | K2 → K4 → K5 | 診断 Bot（集客開始可能になる） |
| 3 | K6 → K7 | 受任・収集 |
| 4 | K8 → K9 | 計画書・申請 |
| 5 | K11 → K12 | 報酬・受け入れ検査 |

- H 系列との合流: K2/K5/K6 は相続放棄の H2/H7/H8 完了が前提。
  相続放棄より補助金を先行させたい場合は **H2/H7/H8 だけを先に発注**すればよい
  （3タスクともユニット非依存の一般化タスクであり、相続放棄固有部分を含まない）
