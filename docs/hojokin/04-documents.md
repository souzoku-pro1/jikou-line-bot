# 04. 書類生成：事業計画書の AI 下書きと申請パッケージ

## 1. AI の役割の縛り（明文化）

**AI（Claude）の役割は「構成と初稿」に限定する。**

| 領域 | AI がやる | 人がやる（弁護士＋顧客） |
|---|---|---|
| 構成 | 公募類型別テンプレートの章立てに、ヒアリング結果を**振り分ける** | 章立て自体の妥当性確認 |
| 初稿 | 各章の文章化（**ヒアリングで得た事実の整理・言い換えのみ**。事実の創作禁止） | 全文の書き直し・肉付け |
| 数値計画 | 顧客提供の数値の**転記と四則演算**（売上計画表の整形） | **数値そのものの妥当性・実現可能性**（採択審査の中核） |
| 加点戦略 | 加点チェックリストの機械照合（§3） | 加点を取りに行く経営判断（賃上げ表明等） |
| 市場・競合分析 | 顧客の回答の整理のみ（**Web 情報の引用・生成をしない**） | 分析の実質 |
| 審査項目への適合 | — | **審査観点の読み込みと戦略**（弁護士） |

- 実装ガード: 生成プロンプトに「ヒアリング JSON に無い事実・数値を書かない。
  不足箇所は `【要記入: ○○】` を残す」を固定。**生成物はそのまま提出できない体裁**
  （透かし「下書き」+ 要記入マーカー）とし、`計画書確定=yes`（弁護士のみ）を経ないと
  申請パッケージに入らない（相続放棄の `文案確定` ガードと同型）
- 採択可能性・採択率の推定値を計画書・顧客向け文面に出力することを禁止（02 §5 禁則と同じ）

## 2. 入力: 事業計画ヒアリングの構造化

診断（02）完了後・受任後に Bot が追加ヒアリング（tool use・逐次 upsert・H3 の型）:

| 区分 | 項目 |
|---|---|
| 現状 | 事業概要 / 主要顧客・販路 / 直近の経営課題 / 売上・利益の直近実績（数値は顧客提供） |
| 取組 | 投資・取組の内容 / 費用の内訳（見積書と紐付け） / スケジュール |
| 効果 | 期待する効果（定量・定性） / 売上計画の前提 |
| 体制 | 実施体制 / 賃上げ等の加点関連の予定 |

- 格納先: App 41 `事業計画データ`（JSON）。文章はここから生成し、**Bot の回答以外を
  出典にしない**（§1 の縛りの実装点）

## 3. 生成物

| 成果物 | 生成方法 |
|---|---|
| 事業計画書 初稿 docx | `docx_templates/hojokin/<公募類型>.docx`（持続化 / IT導入 / 再構築 / ものづくり / 汎用 の類型別テンプレート・規約配置）＋ fill_template / fill_table_rows（S2 の拡張を流用） |
| 加点チェックリスト | 公募マスタ `加点項目` SUBTABLE から生成。各項目に 対応済み/未対応/対象外 を人がチェック → 未対応があれば承認画面に警告表示（取りこぼしの機械検知） |
| 経費明細表 | 見積書（M5 受領）から品目・金額を抽出し様式に転記（人が検算） |

- 公募類型テンプレートの追加も**ファイル配置のみ**（規約: 公募マスタに `計画書テンプレ名`
  を持たせ、無ければ `汎用.docx`）。コード変更ゼロの原則を維持

## 4. 申請パッケージ（提出 API がないための転記支援・01 §0）

`計画書確定=yes` かつ 書類チェック全受領 で App 30 に自動起票（承認待ち）:

| 同梱物 | 内容 |
|---|---|
| 添付書類一式 | 事業計画書 PDF・決算書等の受領済みファイル（チェックリスト順・jGrants の添付名規則でリネーム） |
| **jGrants 転記シート** | jGrants の入力フォーム項目（事業者情報・事業名・補助事業の内容・経費内訳…）を**画面の入力順に並べた1枚の docx**。事務員はこれを見ながら転記するだけ（転記ミス・入力漏れの防止） |
| 提出前チェックリスト | 締切日時・GBizID 委任確認・添付漏れ・ファイルサイズ制限等 |

- ✅ 弁護士承認 → 👤 提出 → 提出日時・受付番号を案件に記録（1操作）
- 実績報告（フロー[7]）も同じパッケージ方式（証憑一式＋転記シート）

## 5. テスト観点（K 系列の完了条件用）

- 生成ガード: JSON に無い数値が初稿に現れない（差分検査テスト）・要記入マーカー残置・
  計画書確定=no でパッケージ生成拒否
- 類型テンプレート解決: 公募マスタ指定→ファイル→汎用フォールバック
- 加点チェックリスト・経費明細の生成（ゴールデンファイル）
- 転記シート: 公募マスタの様式項目定義から生成されること（項目追加がマスタのみで済む）
