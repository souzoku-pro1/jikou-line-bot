# 08. 実装タスク分解とハブタスク台帳との統合実装順序

相続放棄ユニットのタスクは **H系列**。発送/受領ハブの **T系列**
（[docs/architecture/09-implementation-plan.md](../architecture/09-implementation-plan.md)・全19+1タスク）
への依存を各タスクに明示する。発注方法・プロンプト雛形・全タスク共通の完了条件
（既存テスト全 PASS）はハブ 09 §2 と同一。

## 1. ハブタスクへの依存関係（サマリ）

```
T0-1..T0-3（hub基盤）─────► H1 H2 H5 H6 H7 H8 …（全Hタスクの前提）
T1-1..T1-4（App30・承認/dispatch・ラベル・期限ジョブ）─► H13（裁判所発送）
T2-1..T2-2（M4 送付案内）────────────────► H13 H14 H15（裁判所・依頼者への郵送）
T3-1..T3-3（M1 職務上請求）───────────────► H10（戸籍収集の自動起票）
T4-1..T4-2（M5 スキャン受領）──────────────► H11（書類消込・照会書受領）
T5-x（M2 e内容証明）/ T6-x（M3 FAX）: 相続放棄 v1 では不要（依存なし）
```

相続放棄ユニット内の依存:

```
H1(App33) ─► H3(ヒアリング) ─► H4(複雑性・チャネル)
H2(LINEチャネル) ─┘                └─► H6(予約)
H1 ─► H5(熟慮期間) / H7(トリアージ) / H8(契約決済) ─► H9(受任判断・チェックリスト)
H9 ─► H10(職務上請求連携) / H11(受領連動) / H12(書類生成)
H1 ─► H16(家裁マスタ・管轄確定) ─┐
H12 ────────────────────────────┴► H13(申述パッケージ提出) ─► H14(照会書) ─► H15(仕上げ)
```

## 3. 統合実装順序（T系列 × H系列）

並行レーン付き。同一ステージ内は依存がなく並行発注できる。

| ステージ | ハブ（T系列） | 相続放棄（H系列） | 備考 |
|---|---|---|---|
| 1 | T0-1 → T0-2 → T0-3 | — | 共通基盤。全ての前提 |
| 2 | T1-1 → T1-2、T1-3、T1-4 | H2（並行可） | T6-1 は実施済み |

| 5 | T4-1 → T4-2（M5） | H9 → H12 | |
| 6 | T5-1 → T5-2（M2・時効援用向け） | H10、H16 → H13 | H10 は T3-3 後、H13 は T2-2/H16 後なら前倒し可 |

  T0系 → T1系 → T2系 → H1〜H9 → T3系 → H10/H12/H16/H13 → T4系 → H11 → H14 → H15

  （案件を手動登録しても期限警報だけ先に価値が出る）。早期リリース候補
