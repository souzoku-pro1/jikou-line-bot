## 3原則の継承（docs/architecture/README.md より）

1. **平常時は人間の作業ゼロ、異常時のみ LINE 警報** — 熟慮期間監視・予約枠生成・
   リマインドまで全て日次/定期ジョブ化。人が登場するのは承認・面談実施・警報対応のみ
2. **弁護士名義の対外発信は必ず承認ステップを挟む** — 裁判所への提出物（申述書・上申書・
   照会書回答）は全て発送管理（App 30）の承認済を経由。加えて本ユニットでは
   **法的判断（受任可否・熟慮期間の起算点確定・上申書の内容）も弁護士承認必須**とする
3. **チャネルはアダプタ、案件はユニット** — 相続放棄は UNIT_CONFIG のエントリ追加＋
   マスタ行＋テンプレートで既存チャネル（M1/M4/M5）に乗る。ハブ本体のコード変更なし
   （変更が必要になった箇所は 07 で「ハブ側の一般化タスク」として明示）

## 相続放棄ユニット固有の追加原則

4. **熟慮期間が生命線** — 期限系のデータ（死亡日・知った日・満了日）は Bot の申告値と
   弁護士の確定値を分離して持ち、確定前でも安全側（早い方の日付）で警報する
5. **複雑案件の自動引き上げ** — 複雑性フラグが1つでも立てば、依頼者の希望に関わらず
   非対面（C）を許さず B 以上に引き上げ、その旨を定型文で丁寧に通知する
