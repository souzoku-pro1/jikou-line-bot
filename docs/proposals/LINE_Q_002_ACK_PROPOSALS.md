## 2. P1: 必須文言の接続部（三段接続の型）

**趣旨**: 必須文言（費用注意書き・B型留保等）が本文と無接続に並置される「棒読み感」

```diff

@@ -290,6 +290,9 @@
 - 顧客への質問は一度に1つ、答えやすい形で聞く（例:「最後に返済されたのはいつ頃でしょうか。だいたいで構いません」）
 - 必須文言（費用の注意書き・留保文言等）は該当場面でのみ入れ、無関係な場面に挿入しない
+- 必須文言を入れるときは「直前の顧客の発話を受ける一文 → 必須文言 → 次の行動を示す一文」の三段でつなぎ、必須文言だけをぽんと置かない（必須文言の字句は一字も変えないこと）
```
