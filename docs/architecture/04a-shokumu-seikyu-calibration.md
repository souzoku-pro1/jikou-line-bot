# 職務上請求 統一用紙 実機キャリブレーション手順書（04a・T3-2）

オーナー（あなた）がプリンタの前で行う作業の手順書です。
所要時間の目安: 初回 30〜60分。用紙の版が変わったときだけ再実施します。

## 用意するもの

- [ ] 日弁連統一用紙（複写式）の実物 … 本番用1枚＋座標合わせ用に古い用紙 or コピー数枚
- [ ] 白紙のA4用紙 … 数枚
- [ ] 定規（mm目盛り）
- [ ] このPCとプリンタ

## 大事な前提（1分で読んでください)

- 座標系は **用紙の左下が原点（0, 0）**・単位は **mm**・右へ x・上へ y です
- 現在コードに入っている座標（`channels/shokumu_seikyu.py` の `FORM_COORDS`・26項目）は
  **設計上の仮の値**です。この手順で実測値に置き換えるまで、実用紙とはずれます
- 印刷ダイアログでは必ず **「実際のサイズ」（倍率100%）** を選んでください。
  「用紙に合わせる」「縮小して印刷」だと座標が全部ずれます（最頻出の失敗原因)

## 手順

### 1. 校正用PDFを出力する

PowerShell（このフォルダ＝リポジトリ直下）で:

```powershell
python -m channels.shokumu_seikyu C:\Users\totot\Desktop\校正
```

デスクトップの「校正」フォルダに3つのPDFができます:

| ファイル | 用途 |
|---|---|
| 校正1_方眼と座標キー.pdf | 5mm方眼＋全項目のキー名が現在の座標位置に印字されている |
| 校正2_サンプル重ね打ち.pdf | サンプルデータ（山田太郎の架空事件）を方眼付きで印字 |
| 校正3_レターパック方眼.pdf | レターパックラベル（100×70mm）の方眼確認用 |

### 2. 校正1を白紙に印刷し、統一用紙と透かして座標を読む

1. 「校正1_方眼と座標キー.pdf」を白紙A4に印刷（**実際のサイズ・100%**）
2. 印刷した白紙の上に統一用紙を重ね、窓や照明に透かす
3. 用紙の各記入欄について、**その欄の左下あたり（文字を書き始めたい位置）** の座標を
   方眼から読み取ってメモする（5mm方眼・10mmごとに数字あり。定規で補間)
   - 例: 「事務所名の欄 → x=58, y=262」
4. 26項目すべてでなくてOK。**ずれている項目だけ** 新しい値をメモすれば足ります

### 3. 読み取った座標を Claude/Sonnet に伝えて反映してもらう

メモした値をそのまま貼り付けて指示してください。例:

> FORM_COORDS を実測値で更新して。事務所名 (58, 262)、弁護士氏名 (58, 254)、
> 対象者本籍 (48, 224)、…（読み取った項目を列挙）。FORM_VERSION も上げて。

（自分で `channels/shokumu_seikyu.py` の `FORM_COORDS` を直接編集しても構いません）

### 4. サンプル重ね打ちで確認する

1. 座標更新後、もう一度手順1のコマンドを実行して「校正2_サンプル重ね打ち.pdf」を出し直す
2. **統一用紙のコピー**（本物はまだ使わない）に印刷して、各欄に文字が収まっているか確認
3. まだずれている欄があれば、手順2〜3を繰り返す（普通は1〜2往復で合います)

### 5. 全体が一律にずれるときはオフセットで直す

「全部の文字が同じ方向に 2mm ずれている」ような場合は、座標表ではなく
プリンタ個体差です。環境変数で一括補正します:

```powershell
railway variables --set "PRINT_OFFSET_X_MM=1.5" --set "PRINT_OFFSET_Y_MM=-2"
```

- 右にずらしたい → X をプラス / 上にずらしたい → Y をプラス（小数OK・マイナスOK）
- ローカルで試すときは PowerShell で `$env:PRINT_OFFSET_X_MM="1.5"` を設定してから手順1を実行
- ※Railway に設定すると本番の全PDF（送付案内の宛名ラベル等も）に効きます。
  このオフセットは「事務所のプリンタ個体差」用なので、それで正しい挙動です

### 6. 本番用紙で最終確認

1. 複写式のため **手差しトレイに1枚だけ** セット（印字面・向きに注意。
   最初は失敗してよい用紙で向きを確かめてください）
2. 「校正2_サンプル重ね打ち.pdf」…ではなく、方眼なしの実運用と同じ出力で確認したい場合は
   kintone でテスト起票して成果物の「職務上請求書_重ね打ち.pdf」を印刷
3. 複写の2枚目・3枚目まで文字が写っているか確認（薄ければプリンタの印字濃度を上げる)

### 7. 完了の記録

確認が済んだら Claude/Sonnet に「キャリブレーション完了。FORM_VERSION を確定版にして」と
伝えてください（`FORM_VERSION` を「v1-実測済み（YYYY-MM-DD・用紙の版名）」に更新します）。

## レターパックラベル（校正3）について

- ラベルは 100×70mm 想定で、印刷して**レターパックの「お届け先」欄に貼る**運用です
- 「校正3_レターパック方眼.pdf」を一度印刷し、お届け先欄に収まるサイズか確認してください
- 往復ラベルPDFは2ページ構成: **1ページ目=宛先（自治体・御中）/ 2ページ目=返信用（事務所・行）**。
  2ページ目は同封する返信用レターパックに貼ります

## トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| 全項目が同じ方向にずれる | 手順5のオフセットで一括補正 |
| 特定の欄だけずれる | その欄だけ FORM_COORDS を実測値に更新（手順2〜3） |
| 拡大/縮小されたようにずれ幅が場所で違う | 印刷倍率が100%になっていない。「実際のサイズ」を選ぶ |
| 文字が欄からはみ出す | 長文は自動縮小されるが下限6pt。チャネル固有データの文言を短くするか、`_FORM_MAX_WIDTH_MM` の幅を実測値に更新 |
| チェック印「レ」の位置が □ に合わない | チェック欄は □ の中心よりやや左下を狙って座標を取る |
| 用紙の版が変わった | この手順を最初から。完了後 FORM_VERSION を更新 |
