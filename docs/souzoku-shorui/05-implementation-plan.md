## 4. 推奨実装順序（T/H との合流込み）

| 順 | タスク | 備考 |
|---|---|---|
| 0 | S0（人）＋ T0-3 完了待ち | S0 は今日でも可能（scriptId 提供のみ） |
| 1 | S1、S2 | 相互独立・並行発注可 |
| 2 | S3 | 目録が最初の成果物（財産データ整備の価値が即出る） |
| 3 | S4（T1-2 後）、S5（T4-1 後） | 入力自動化。ハブ進捗と合流 |
| 4 | S6 | 協議書 |

| 6 | S9（T2-2 後） | 発送結線・仕上げ |

  からでも目録が生成できる）。相続放棄 H5 と同様の早期リリース候補
