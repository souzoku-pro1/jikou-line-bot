## 共通原則

1. **半自動**: AI 出力は常に「未確認」状態で保存され、人の確認（03 の UI）を経ないと
   下流（相続人確定・関係図・一覧図・App 37）に流れない
2. 複雑ケース（代襲・数次・順位繰上り等）は機械が**確定せず**フラグを立てて弁護士判断（04 §3）
3. 対外提出物（法定相続情報一覧図の申出）は App 30 承認必須（既存原則）
4. 預貯金整理の用途は**遺産整理の財産調査に限定**（使い込み調査は商品廃止済みのためスコープ外・06 §0）
