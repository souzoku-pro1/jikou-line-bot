## 6. 収載本文の同一性の再確認手順（READ_ONLY）

各ファイルについて、境界マーカー行より後ろのバイト列の SHA-256 が第1節の「原本 SHA-256」と一致することを確認する:

```bash
python -c "
import hashlib,sys
p=sys.argv[1]; d=open(p,'rb').read()
m=[l for l in d.split(b'\n') if b'ORIGINAL-TEXT-BELOW' in l][0]+b'\n'
i=d.find(m); print(hashlib.sha256(d[i+len(m):]).hexdigest())
" docs/plan/2026-08_execution-plan.md
```
