# 時効案件進行アプリの使い方（大野向け 1 ページ・JIKOU-STAGE-APP-1）

**流れ: スマホで開く → 電話 → ボタン → 10 分以内なら取消。** 依頼者への報告（LINE）と完了報告書はボタン 1 回で済みます。

## 1. スマホで開く

- kintone アプリ「時効案件進行」→ 一覧「回答待ち（発送日順）」。1 行＝1 社。上から順に電話します。
- 一覧「確認漏れ」は、回答受領日を入れたのに確認ボタンを押していないもの（既定 7 日超）。

## 2. 電話で確認する

1. レコードを開く。上部の **債権者電話番号** をタップして発信。
2. 画面の **氏名・生年月日・住所・契約番号** で本人特定に答える（この欄はこのアプリにしかない控えです。依頼者の連絡先は書かない）。
3. 回答を聞いたら **回答受領日**（今日）と **回答内容メモ**（要旨。依頼者の電話番号などは書かない＝報告書に出ます）を入力して保存。

## 3. ボタンを押す（＝承認）

- 時効完成を認めた → **「時効確認済にする」**。
- 認めない → **「不成立にする」**。

押すと **10 分の猶予**（`JIKOU_CONFIRM_GRACE_MIN`・0 なら即時）の後に、ボットが

1. 結果記録を保存し、
2. 完了報告書 PDF を作り、
3. 承認済みの固定文と **本人専用 URL（72 時間有効・名前や番号は URL に出ない）** を依頼者の LINE に送り、
4. 状態を「報告済」にして送信日時・版番号を記録します。

不成立は証明書なしで固定文のみ。全社が報告済になると「全件完了」の固定文が 1 通届き、状態は「完了」になります。

## 4. 取り消す（押し間違い）

- 10 分以内に **「回答待ちに戻す」** を押す → 送りません。10 分を過ぎて送られた後の取消はできません（依頼者に届いています）。

## 5. 「要対応」が付いたら

- 業務 LINE に「【時効案件進行: 要対応】レコードNo・理由コード」が届きます。依頼者には何も送られていません。
- よくある理由: `answered_on_missing`（回答受領日が空）→ 入力して「回答待ちに戻す」→ もう一度ボタン。`text_unapproved`（固定文が未承認）→ 司令塔の票で承認。
  `cert_…`（報告書が作れない: 発送日なし・宛名なし等）→ 結果記録／App 21 を直して再度。`send_…`（LINE 送信失敗）→ 時間をおいて「回答待ちに戻す」→ ボタン。
- 直したら「要対応」のチェックを外してください。

## 6. やらないこと

- このアプリから依頼者へ自由文は送れません（固定文のみ）。文言を変えるときは司令塔の票で承認台帳を更新します。
- 「入金確認」「発送済」「回答待ち」はボットが進めます（手で動かしても害はありませんが戻さないでください）。
